# Icons for the gate poster PDF

Five Lucide icons (https://lucide.dev, lucide-react 1.57.0), drawn as vectors on the gate poster
(spec M2 §7 rule 20, F-34). They were made from the icon data in `lucide-react` with a small
script: same shapes, stroke black instead of `currentColor`.

| File | Use on the poster |
|---|---|
| `id-card.svg` | 1. Show your ID card to the camera |
| `scan-face.svg` | 2. Look at the camera |
| `log-in.svg` | 3. See IN or OUT on the screen |
| `octagon-x.svg` | If it says NOT ACCEPTED |
| `shield-check.svg` | The privacy notice |
