Four kiosk files for spec docs/specs/M2-qr-attendance.md section 4.1 to 4.5. Same look as the approved M1 pairing screens and gate A ("Steel & Signal", Inter, yellow only as the scan language). Primary size 1280 x 800; the scanning screen and one result are also drawn at 1366 x 768 and 390 x 844 (see screenshots/, names end in -1366x768 or -390x844). Add ?shot to a URL to hide the state tag. Read notes.md for decisions, contrast table and open questions.
