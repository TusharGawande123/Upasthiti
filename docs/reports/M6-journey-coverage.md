# M6 journey coverage (AC-M6-5 to AC-M6-8, decision 0038)

Per decision 0038 a journey is written only for what no existing e2e spec already proves. "Written" journeys are in
`e2e/journeys/` (run with `npm run journeys` in `e2e/`, headed, one after another, on the local throw-away database;
they are not part of the required CI `e2e` check). They were written WITHOUT running the browser: the first headed
run is done by the coordinator. "Covered" means an existing spec proves the journey; "not covered" lists what is
still open in a journey that is only partly proved.
