# M6 acceptance-criteria matrix (milestones M0 to M5c)

Status: First pass done 2026-11-05 (plan slice 0.2). Rows marked `GAP` get a test in plan phase 5; the final
state has no `GAP` row. The `--check` mode of `backend/scripts/ac_matrix.py` keeps this file honest: every
criterion of the specs has one row, a valid status, and evidence files that exist.

How to read it:
- **Covered**: a named test proves the current behaviour.
- **Gap added**: was a gap, a test was added in M6 (evidence names it).
- **Superseded**: a later decision or spec replaced the criterion (the note names it).
- **Manual**: only a real device or a person can check it; it is in the manual checklist.
- **Accepted gap**: cannot reasonably be tested; the note gives the reason.
- **GAP**: no test found yet; the note says what the new test must check.

Some criteria in the old specs use outdated numbers or words (for example `/kiosk`, old coverage floors,
overtime for permanent staff). The note of the row says what is current. The specs are not rewritten.
